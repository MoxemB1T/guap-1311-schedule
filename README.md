# Расписание 1311 — Telegram Mini App

Готовое статическое приложение: его можно полностью бесплатно разместить на **GitHub Pages** или **Cloudflare Pages**. Для расписания уже внесены общие занятия и занятия подгрупп, указанные в сообщении. При первом открытии студент выбирает подгруппу, после чего видит красивый последовательный список ближайших 14 дней с датой, днём недели и цветом недели.

## Что нужно сделать один раз

### 1. Создать бесплатную базу Supabase

1. Зарегистрируйтесь на [Supabase](https://supabase.com/) и создайте проект на Free plan.
2. В **SQL Editor** вставьте содержимое файла `supabase.sql` и нажмите Run.
3. В **Edge Functions** создайте функцию `admin-schedule`, вставьте в неё содержимое `supabase/functions/admin-schedule/index.ts` и нажмите Deploy. В **Project Settings → Edge Functions → Secrets** добавьте секрет `TELEGRAM_BOT_TOKEN` — токен вашего бота из BotFather. Этот токен нельзя добавлять в сайт или `config.js`.
4. В **Project Settings → API** скопируйте `Project URL` и `anon public key` в `config.js`:

```js
window.APP_CONFIG = {
  supabaseUrl: 'https://ваш-проект.supabase.co',
  supabaseAnonKey: 'ваш-anon-public-key'
};
```

`anon public key` можно размещать в приложении: он не даёт прав на редактирование. Редактирование защищено правилом в базе.

### 2. Бесплатно опубликовать сайт на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `guap-1311-schedule`, и загрузите в него **все файлы из этой папки**.
2. В репозитории откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите Save.
3. Через пару минут GitHub покажет адрес вида `https://ваш-логин.github.io/guap-1311-schedule/`. Откройте его в браузере и проверьте расписание.

Cloudflare Pages — равнозначная бесплатная альтернатива: подключите тот же репозиторий, без команды сборки, publish directory `/`.

### 3. Подключить к Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather), если его ещё нет.
2. Откройте **/mybots → ваш бот → Bot Settings → Menu Button → Configure menu button**.
3. Укажите название «Расписание 1311» и ссылку GitHub Pages из прошлого шага.

Теперь Mini App откроется кнопкой меню в личном чате с ботом. Бэкенд и сервер для бота не нужны — это и делает решение бесплатным.

## Как редактировать

В приложении нажмите ⚙ прямо внутри Telegram. Панель доступна только аккаунту с Telegram ID `559546940` (`@moxem_b1t`); email, пароль и отдельная регистрация не нужны. Можно добавлять, менять или удалять занятия, а также выбирать, синяя или красная неделя идёт сейчас. После сохранения данные мгновенно становятся общими для всех.

## Важное уточнение по расписанию

Стрелка **вниз** внесена как синяя неделя, стрелка **вверх** — как красная. Общие занятия показаны обеим подгруппам. В понедельник на 3-й паре указанная «Реверсивный инжиниринг…» не внесена, поскольку в отдельном расписании она распределена на среду (подгруппа 2) и четверг (подгруппа 1). Если это не так, занятие можно добавить через админ-панель.
